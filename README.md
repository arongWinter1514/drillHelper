# 圖點預習小助手

大家早安，歡迎使用圖點預習小助手。

本網頁之目的為協助樂旗隊隊員完成圖點預習步驟中較為繁瑣的計算，並顯示總圖點供隊員們參考，以幫助隊員們在練圖前順利完成完整的圖點預習。

-

以下是各位可能會有的疑問：

Q：我可以直接匯入教練給的pdf檔，讓網頁自動幫我辨識絕標嗎？<br>
A：不行。絕標請自己寫，不要把圖點預習指南當塑膠。

Q：為什麼我無法直接下載步伐大小、中點和過碼線的計算結果？<br>
A：因為本網頁並未提供下載計算結果的功能。<br>
　　你可以✅：自己動動手把計算結果抄到圖上。<br>
　　不可以❌：螢幕截圖、列印網頁、複製貼上到 Word...等等。
